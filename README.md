# Wake Word

An alarm clock that only turns off once you finish a short mission in another language: pick the right word, fill in a blank, type it from English, say it out loud, or find the real object and photograph it.

Languages: Italian, Spanish, French (250 words each, from everyday words to idioms) and German (32 words). Words come back on a spaced schedule (1, 2, 4, 7, 14, 30 days), and a miss sends a word back to day one.

## What's in here

| Path | What it is |
| --- | --- |
| `App.tsx`, `src/` | The app screens, the learning logic (`src/logic.ts`) and the word decks (`src/decks.ts`) |
| `modules/wake-alarm/` | The native alarm: AlarmKit on iPhone, AlarmManager plus a full-screen alarm on Android |
| `plugins/` | Expo config plugin that wires the alarm into the iOS and Android projects |
| `photo-check/` | Optional Cloudflare Worker that asks Claude whether a photo shows the right object |
| `tests/` | Tests for the learning logic (`npm test`) |
| `assets-b64/` | App icons, the alarm tone and the alarm songs as text; `npm install` turns them back into `assets/` |
| `tools/make_songs.py` | Makes the alarm songs: instrumental versions of traditional and public-domain tunes (needs Python, numpy, ffmpeg) |

Built with Expo SDK 58 (React Native 0.88). The `ios/` and `android/` folders are generated by `npx expo prebuild` and aren't kept in the repo.

## How the alarm stays on

**iPhone (iOS 26 or later, AlarmKit).** The alarm rings through silent mode and the lock screen. iOS always shows a button that stops the sound, so that button is labelled Snooze: if today's mission isn't done, it rings again a minute later. Open stops the sound and opens the mission. While the mission is on screen the app keeps pushing the next ring back; leave the app and it rings again. This repeats for up to 60 minutes after the alarm time.

**Android.** The alarm starts a foreground service that loops the alarm sound and shows a full-screen alarm over the lock screen, with no stop button. Starting the mission quiets the sound, and it comes back if the app goes quiet for 90 seconds. Only finishing the mission stops the service. Alarms are set again after a restart.

## Try it

```bash
npm install
npm test
```

**Preview the missions (no alarm):** `npx expo start`, then open it in Expo Go on a phone. Expo Go can't set alarms, so the app says so and lets you practise.

**Android phone (free):** connect the phone with USB debugging on and run `npx expo run:android` (needs Android Studio), or build an installable APK on Expo's free tier with `npx eas-cli build -p android --profile preview` (needs a free Expo account; the APK link appears when the build finishes).

**iPhone:** needs iOS 26 or later and a Mac with Xcode.
- With a free Apple ID: `npx expo run:ios --device`. The app stops opening after 7 days and has to be installed again from the Mac.
- To keep it installed, or to install without a Mac (EAS build), you need the paid Apple Developer Program ($99 a year).

## Photo checking (optional)

Without a checker, the app asks you to confirm your own photo ("Is that the stove?"). To have Claude check it:

```bash
cd photo-check
npm install
npx wrangler login                          # free Cloudflare account
npx wrangler secret put ANTHROPIC_API_KEY   # your Anthropic API key, kept on the server
npx wrangler secret put APP_TOKEN           # optional: any random string
npx wrangler deploy
```

Then put the worker's address in `app.json` under `expo.extra.photoCheckUrl` (and the same random string in `photoCheckToken` if you set one), and rebuild the app. The API key never goes in the app. Each check is one small Claude request, billed to that key.

## Not yet tested

This was written on a Linux machine, so the Swift (iOS alarm) and Kotlin (Android alarm) code has never been compiled or run on a phone. The learning logic is tested, the TypeScript typechecks and lints clean, and `expo prebuild` generates both native projects with the alarm, camera, microphone and speech permissions in place. Expect a few fixes on the first real build, then test with "Test: ring in 1 minute" on the home screen.
